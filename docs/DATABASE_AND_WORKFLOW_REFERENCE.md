# مرجع قاعدة البيانات ومسارات العمل — تطبيق طلبات البيت للمندوب
# Talabat Al-Bayt Driver — Database & Workflow Specification Reference

> هذا الملف يمثل المرجع التوثيقي المعتمد لقاعدة بيانات Supabase، وجداولها، وعلاقاتها، ودوال RPC، ومسارات العمل المستخرجة من الكود المرجعي لتطبيق المندوب.

---

## 1. تصنيف الجداول حسب مسارات العمل

### أ. مسار طلبات التوصيل العادية (Regular Delivery)
1. **`delivery_drivers`**: جدول بيانات المندوب الأساسية وبيانات اعتماده ونطاق عمله.
2. **`delivery_orders`**: جدول طلبات التوصيل العادية وحالاتها وإسنادها.
3. **`delivery_order_items`**: جدول أصناف الطلب وكمياتها وحالة شرائها.
4. **`delivery_order_status_history`**: سجل الحالات الزمنية للطلب.
5. **`delivery_settings`**: الإعدادات العامة لخدمة التوصيل.
6. **`delivery_governorate_settings`**: إعدادات المحافظات ونطاقات التوصيل والتسعير.

### ب. مسار طلبات الصيدلية (Pharmacy Orders)
1. **`pharmacy_orders`**: جدول بيانات طلب الصيدلية الأساسية والمريض والعنوان.
2. **`pharmacy_delivery_orders`**: جدول ربط طلب الصيدلية بطلب التوصيل والمندوب المسند.
3. **`pharmacy_order_items`**: جدول الأدوية والمستلزمات الطبية والجرعات وحالة توفرها.
4. **`pharmacy_order_files`**: جدول مرفقات الطلب (صور الروشتات، وفواتير الصيدلية).
5. **`pharmacy_order_pharmacy_stops`**: جدول محطات الصيدليات التي يمر عليها المندوب لاستلام الدواء.
6. **`pharmacy_pharmacies`**: جدول بيانات الصيدليات وفروعها وعناوينها وهواتفها.
7. **`pharmacy_driver_compensation`**: جدول تعويضات وأجور المندوب لطلبات الصيدلية.
8. **`pharmacy_saved_prescriptions`**: الروشتات والوصفات الطبية المحفوظة للمريض.
9. **`pharmacy_saved_prescription_items`**: عناصر وأدوية الروشتات المحفوظة.
10. **`pharmacy_shortage_reason_suggestions`**: اقتراحات وأسباب نقص الأدوية وبدائلها.
11. **`household_addresses`**: عناوين المنازل المربوطة بحساب العميل.
12. **`households`**: بيانات المنازل والعملاء المرتبطة بالطلب.

## 3. دوال RPC المثبتة ومعاملاتها الفعلية

### أ. دوال مسار التوصيل العادي (`Regular Delivery RPCs`)
1. **`accept_delivery_order`**:
   - **المرحلة:** عند قبول الطلب من قائمة الطلبات الجديدة المتاحة.
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **الأثر في الواجهة:** نقل الطلب إلى قائمة الطلبات المقبولة والجارية وإسناد المندوب.
2. **`driver_start_shopping`**:
   - **المرحلة:** عند وصول المندوب للمتجر والبدء بجمع وتجهيز الأصناف.
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **الأثر في الواجهة:** تحويل حالة الطلب إلى تسوق (`shopping`) وفتح قائمة الأصناف لمطابقتها.
3. **`driver_update_delivery_item`**:
   - **المرحلة:** أثناء جمع الأصناف لكل صنف على حدة.
   - **المعاملات الفعلية:** `{ p_item_id: string, p_is_purchased: boolean, p_price?: number, p_notes?: string }`
   - **الأثر في الواجهة:** تحديث حالة شراء الصنف وحساب المجموع الفعلي.
4. **`driver_complete_shopping`**:
   - **المرحلة:** بعد الانتهاء من جمع كافة الأصناف واعتماد فاتورة الشراء.
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **الأثر في الواجهة:** تحويل الطلب إلى جاهز للتوصيل / في الطريق (`delivering`).
5. **`complete_delivery_order`**:
   - **المرحلة:** عند تسليم الطلب للعميل واستلام الحساب إن كان نقديًا.
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **الأثر في الواجهة:** تحويل الطلب إلى مكتمل (`delivered`)، إيداع عمولة المندوب، وأرشفة الطلب في السجل.
6. **`request_order_cancellation`**:
   - **المرحلة:** عند تعذر استكمال الطلب أو رفض العميل أو إغلاق المتجر.
   - **المعاملات الفعلية:** `{ p_order_id: string, p_reason: string, p_driver_id: string }`
   - **الأثر في الواجهة:** رفع طلب إلغاء للإدارة ونقل الطلب لقائمة الملغاة.

### ب. دوال مسار طلبات الصيدلية (`Pharmacy Delivery RPCs`)
1. **`pharmacy_driver_accept_order`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **المرحلة:** قبول طلب الصيدلية من قائمة المعروضات.
2. **`pharmacy_driver_start_shopping`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **المرحلة:** التوجه للصيدلية وبدء تجهيز الروشتة.
3. **`pharmacy_driver_update_item`**:
   - **المعاملات الفعلية:** `{ p_item_id: string, p_status: string, p_price?: number, p_notes?: string }`
   - **المرحلة:** تأكيد توفر كل دواء، أو تسجيل سبب النقص أو استبداله بالبديل.
4. **`pharmacy_driver_update_image_note`**:
   - **المعاملات الفعلية:** `{ p_file_id: string, p_note: string }`
   - **المرحلة:** إضافة ملاحظات وتفسير خط الروشتة أو عبوة الدواء المرفقة.
5. **`pharmacy_driver_add_pharmacy_stop`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_pharmacy_id: string, p_notes?: string }`
   - **المرحلة:** إضافة صيدلية بديلة أو محطة ثانية إذا كان أحد الأدوية غير متوفر في الصيدلية الأولى.
6. **`pharmacy_driver_add_receipt`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_receipt_url: string, p_amount: number }`
   - **المرحلة:** رفع الفاتورة المعتمدة من الصيدلية وتثبيت المبلغ الرسمي.
7. **`pharmacy_driver_finish_shopping`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **المرحلة:** إنهاء استلام الأدوية من كافة المحطات والتغليف الحراري / المبرد.
8. **`pharmacy_driver_mark_customer_contacted`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **المرحلة:** توثيق التواصل مع المريض قبل التحرك أو لإبلاغه بالبدائل.
9. **`pharmacy_driver_complete_delivery`**:
   - **المعاملات الفعلية:** `{ p_order_id: string, p_driver_id: string }`
   - **المرحلة:** تسليم الدواء للمريض باليد وتأكيد السلامة.
10. **`pharmacy_driver_request_cancel`**:
    - **المعاملات الفعلية:** `{ p_order_id: string, p_reason: string, p_driver_id: string }`
    - **المرحلة:** إلغاء طلب الصيدلية في الحالات الطارئة.

## 4. مخطط مسارات العمل (Workflows)

### أ. مسار طلب التوصيل العادي
```text
[1. تسجيل الدخول عبر Auth]
       │
       ▼
[2. جلب المندوب من delivery_drivers بواسطة user_id]
   - استخراج: id, governorate_name, markaz_name
       │
       ▼
[3. جلب الطلبات من delivery_orders + items:delivery_order_items]
   - التصفية: (assigned_driver_id = driver.id) OR
             (assigned_driver_id IS NULL AND governorate_name = driver.governorate_name)
       │
       ▼
[4. قبول الطلب عبر RPC: accept_delivery_order]
       │
       ▼
[5. التوجه للمتجر وبدء التسوق عبر RPC: driver_start_shopping]
       │
       ▼
[6. مطابقة وتعديل الأصناف عبر RPC: driver_update_delivery_item]
       │
       ▼
[7. إنهاء التسوق عبر RPC: driver_complete_shopping]
       │
       ▼
[8. التوجه للعميل وتسليم الطلب عبر RPC: complete_delivery_order]
       │
       ▼
[9. أرشفة الطلب وتحديث إحصائيات وأرباح المندوب]
```

### ب. مسار طلب الصيدلية
```text
[1. جلب طلبات الصيدلية من pharmacy_orders + العلاقات المتداخلة]
   - pharmacy_delivery_orders (assigned_driver_id)
   - pharmacy_order_items (مع تفعيل الجلب الاحتياطي المباشر إن كانت فارغة)
   - pharmacy_order_pharmacy_stops + pharmacy_pharmacies (بيانات الصيدلية)
   - pharmacy_order_files (صور الروشتات والفواتير)
       │
       ▼
[2. التصفية حسب assigned_driver_id أو النطاق الجغرافي]
       │
       ▼
[3. قبول الطلب عبر RPC: pharmacy_driver_accept_order]
       │
       ▼
[4. بدء التسوق والتجهيز عبر RPC: pharmacy_driver_start_shopping]
       │
       ▼
[5. مطابقة الأدوية وتدوين النواقص عبر RPC: pharmacy_driver_update_item]
   - إضافة محطة صيدلية أخرى إذا لزم: pharmacy_driver_add_pharmacy_stop
       │
       ▼
[6. رفع صورة الفاتورة عبر RPC: pharmacy_driver_add_receipt]
       │
       ▼
[7. إنهاء استلام الأدوية عبر RPC: pharmacy_driver_finish_shopping]
       │
       ▼
[8. تسليم الأدوية للمريض عبر RPC: pharmacy_driver_complete_delivery]
```

## 5. مقارنة المشروع الحالي مع المرجع المثبت

| العنصر | في المرجع المثبت | في كود المشروع السابق | التعديل والإصلاح المنفّذ |
| :--- | :--- | :--- | :--- |
| **معرّف المندوب في الطلب** | `assigned_driver_id` | كان يستخدم `driver_id` الافتراضي | تم التحديث لاستخدام `assigned_driver_id` مع دعم احتياطي لـ `driver_id` |
| **بيانات نطاق المندوب** | `governorate_name` و `markaz_name` | كان يفترض `governorate` و `center` | تم استخراج وتطبيق `governorate_name` و `markaz_name` ومطابقتها |
| **استعلام عناصر طلب التوصيل** | `items:delivery_order_items(*)` | كان يجلب `delivery_order_items(*)` بدون اسم العلاقة `items` | تم تحديث الاستعلام لـ `*, items:delivery_order_items(*)` مع الجلب المباشر الاحتياطي |
| **دوال RPC للطلبات العادية** | `accept_delivery_order`, `driver_start_shopping`, `complete_delivery_order` إلخ | كان يستدعي دوالاً بتسميات عامة غير مثبتة | تم استدعاء دوال RPC المرجعية المثبتة نصياً بمعاملاتها الصحيحة |
| **دوال RPC لطلبات الصيدلية** | `pharmacy_driver_accept_order`, `pharmacy_driver_start_shopping`, `pharmacy_driver_add_receipt` إلخ | كان يستدعي `accept_pharmacy_delivery_order` غير المثبتة | تم استدعاء دوال RPC المرجعية الخاصة بالصيدلية مع المحافظة على التحديث المباشر الاحتياطي |
| **جلب محطات وعناوين الصيدليات** | `pharmacy_order_pharmacy_stops(*, pharmacy_pharmacies(*))` | كان يقتصر على أعمدة المتجر العامة | تم استخراج الصيدلية الحقيقية وعنوانها وهاتفها من الجداول المرجعية |
| **صور الروشتات وفواتير الصيدلية** | `pharmacy_order_files` مع ربط `file_type` | كان يعتمد على حقول صور في الطلب نفسه | استخراج المرفقات بدقة من جدول `pharmacy_order_files` المخصص |
